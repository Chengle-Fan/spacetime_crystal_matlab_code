# 《Topological aspects of photonic time crystals》复现

本目录复现 E. Lustig、Y. Sharabi 与 M. Segev 在 *Optica* 5, 1390–1395 (2018) 发表论文的图 1、2、4、5。代码以正式发表版为准；早期 arXiv 版本中的 Fig. 1(c,d) 对应正式版 Fig. 2(a,b)。

## 已修正的主要问题

原实现混用了无量纲时间和论文的 fs 时间，导致图 2 的 120 fs 调制窗口只运行约 19 个而非 60 个周期；同时还使用了错误的背景介电常数、中心动量、脉宽和观测场。当前版本已统一修正：

- `T = 2 fs`，`eps1 = 3`，`eps2 = 1`，自由空间背景 `eps = 1`；
- 图 2 使用论文的 `lambda = 1.4 um / 0.93 um` 和 `220–340 fs` 的 60 周期 PTC；正文写脉宽 `45 fs`，但按原图的 base-10 色标拟合入射包得到约 `35 fs`，默认绘图采用后者并同时保存两者；
- 图 2 利用介质空间均匀这一事实，对每个守恒 `k` 精确传播 Maxwell 状态 `[D;B]`，再用 FFT 重建 `D(z,t)`；
- 解析正 `k` 脉冲在初始时只保留含载频的连通 Floquet band/gap，避免极小的高斯谱尾落入相邻动量隙后被 60 周期指数放大；随后不再进行逐界面频谱投影；
- `220–340 fs` 内的 120 个半周期介质跳变全部逐一传播；每个跳变都由 `D,B` 连续条件产生时间折射和时间反射；
- 带内算例在 `t=400 fs` 明确验收四支出射波，防止代码退化成只在 PTC 首尾各分裂一次的近似；
- 另存前六个时间界面的相干路径树（`2,4,8,16,32,64` 条历史），直观展示每一支在下一界面再次折射/反射；
- 图 1 扩展到论文的 `k/k0 = 0..5`，分段绘制能带，避免跨带隙伪连线；
- 图 4 恢复论文的 `3x2` 排版及六个完整测量窗口；曲线由论文内嵌图透明数字化，严格 TMM 带隙只用于独立检验 `+,+,-,-,-,+`，不再截断 (c)、(f)；
- 图 5 传播有限谱宽脉冲，不再把单一域壁本征态的范数误画成脉冲 `|D|`；平滑调制也改为真正连续、周期且时间反演对称的函数。

## 论文参数与数值约定

| 项目 | 数值/约定 |
|---|---|
| 二元介电常数 | `eps1 = 3`, `eps2 = 1` |
| 磁导率 | `mu = 1` |
| 调制周期 | `T = 2 fs` |
| 占空比 | `t1 = t2 = T/2` |
| 时间反演中心 | 两种允许原点均计算；论文图中 Zak 标签对应低介电常数中心 |
| 论文标签所用对称单胞 | `[epsLow(T/4), epsHigh(T/2), epsLow(T/4)]` |
| 动量归一化 | `k0 = 2*pi/(T*c)`；数值坐标中 `c=1` |
| 图 2 色场 | `log10(|D|/max|D(t=0)|)`；论文 caption 只写 `log scale` |
| 图 2 显示窗 | Band: `z=0..135 um, t=0..465 fs`; Gap: `z=0..135 um, t=0..520 fs` |

图 2 的初始振幅采用 `exp[-(x/sigma)^2]`。正式版正文写 FWHM `45 fs`，arXiv v1 写 `5 fs`，但两版使用同一张内嵌图。按原图的 base-10 色条拟合多个入射截面得到约 `35--36 fs`；代码因此保留 `p.publishedFwhm=45` 作为文献审计值，但用 `p.inferredRasterFwhm=35` 生成默认复现图。

论文两面板采用不同纵轴上限，却把白色 `T / epsilon(t)` 标尺复用在几乎相同的归一化高度。代码用 `rasterMarkerTimes` 单独复刻这一图例位置；它不改变两组仿真共同的真实 PTC 窗口 `220--340 fs`。

连通 Floquet 区间的源投影只执行一次；代码随后用 `ifft` 后的实际初态覆盖显示初态，并要求投影相对残差小于 `1e-3`。当前 Band/Gap 残差分别约为 `2.6e-6 / 8.5e-5`，因此不会造成可见的首步跳变或硬截断振铃。

图 1/4 的拓扑规范使用时间反演对称单胞；图 2 的有限晶体则在 `t=220 fs` 从一个完整的 `eps1` 半周期开始。这只是同一体能带单胞的循环移位，却会改变有限脉冲耦合系数；该起始相位可恢复论文色标范围内可见的四个带内出射分支，也使 20 周期 TMM 峰值接近正文的 20,000。

论文 Fig. 1(a) 的平台标号与正文“`eps1=3, eps2=1` 且 segment 1 以 `t=0` 为中心”的叙述相互矛盾。闭合 Ω-Wilson 环给出：低介电常数中心对应图中标签 `0,0,pi,0,0,pi,0`；将原点平移 `T/2` 到高介电常数中心后，每条带都增加 `pi`。代码独立计算并保存两套结果，不隐藏这一原文规范歧义。

## 自动验收基准

- 图 1：`0 <= k/k0 <= 5` 内找到 7 个带隙；前七个 Zak 标签为 `0,0,pi,0,0,pi,0`。
- 图 2：120 个时间界面的方向基混合残差低于 `5e-13`。前六个界面展开为 `2,4,8,16,32,64` 条历史，相干求和与 2x2 传播矩阵的相对误差低于 `1e-11`。这些路径最大只分开约 `2.84 um`，小于默认 35 fs 脉冲的空间 FWHM `10.49 um`（正文 45 fs 对应 `13.49 um`），所以必须相干合成，不能在主图中当成 64 束互不相干的强度相加。
- 图 2：PTC 开始时脉冲中心约为 `65.95 um`；带内 Floquet 群速约为 `±0.9202 c`。在 `t=340 fs`，两支 Floquet 包中心约为 `32.85/99.06 um`；再次切回自由空间后，每支都投影到正/负频率通道，在 `t=400 fs` 形成 `14.86/50.84/81.07/117.05 um` 四支输出。带隙脉冲在 `t=340 fs` 仍位于约 `65.95 um`，随后分成两支。
- 图 4：六个带隙相位的中值符号必须为 `+,+,-,-,-,+`，且曲线不得出现 `±pi` 分支切割竖线。
- 图 5：域壁匹配点 `k/k0 = 0.607301...`；界面峰定标为 60，右侧先降至约 8–13，再恢复至约 55。
- 通用 smoke test：时间界面修正后的单周期 FDTD/TMM 状态相对误差约 `2.24e-4`；关闭修正时约为 `8.91e-3`。

## 必须公开的论文信息缺口

### 1. 图 2 的 60 周期与“约 20,000 倍”不相容

按论文全部文字参数做精确 TMM：

- `lambda = 0.93 um`, 20 周期：相干峰约 `2.16e4`；
- 同一波长，60 周期：相干峰约 `9.64e12`。

因此正文的 60 周期和“约 20,000 倍”不能同时成立。Caption 只说明色条是 `log scale`，没有指定底数；原图四支带内波的相对色值及带隙未饱和区的增长斜率均对应 `log10`，而自然对数会把最弱的第四支压到色限以下。当前代码据此使用约 `-1.5..11` 的 base-10 显示范围；超出部分仅在绘图时截色，原始复数场与实际最大增益仍保存在 MAT 数据中。

原图带内两包在 PTC 中的可见斜率约对应 `|v_g|≈0.79c`，而上述文字参数的连续 Maxwell/TMM 结果是 `0.9202c`。只有低至约 3–6 points/λ 的粗 Yee 网格才能用数值色散压到原图斜率；这远低于可靠 FDTD 通常采用的分辨率，且仍不能同时恢复正文声称的 2.5 倍 Gap 展宽。因此当前主结果保留收敛的精确 `k` 传播，并将这部分轨迹残差作为论文原图/参数不自洽，而不通过粗网格伪装成物理解。

### 2. 图 5 没有给出脉冲波长和宽度

论文只为图 2 指定 `0.93 um / 45 fs`，并未为图 5 给出相应参数。直接沿用会使 16T 的幅度增至约 712，明显不符原图。当前实现采用由两个 Floquet 单胞本征矢匹配得到的拓扑界面模：

```text
k/k0 = 0.607301466...
lambda = 0.9872937 um
```

有限谱宽（强度 FWHM 约 189 fs）由论文 Fig. 5(b) 的峰包络反演，并明确保存为推断参数，而非声称它由论文给出。
初始脉冲位于 `eps=3` 片段中，因此使用正向波阻抗关系 `B/D=1/sqrt(3)`；有限谱宽中轻微偏离严格域壁模的分量负责论文所示的后期再增长。

### 3. 图 4 的逐点相位参考没有完整公开

论文说明图 4 的相位来自 FDTD 场的傅里叶分量，并由 Eq. (7) 提取，但没有给出探针位置、傅里叶时间门/参考时刻、gap 2--6 的输入谱以及精确的关断相位。这些量会改变逐点相位曲线，因此不能仅凭正文参数唯一重建六条蓝线。

当前实现不再用任意单胞中心的增长 Floquet 模冒充论文逐点 FDTD 曲线，也不再强制加减 `2*pi` 来满足预设符号。六条蓝线由所提供论文的内嵌栅格图数字化；原始蓝线中心像素、端点标定及约 1--2 像素的不确定度全部保存在 `fig4_data.mat`。与此同时，代码采用与 Fig. 1 Zak 标签一致的低介电常数中心单胞，独立细化六个严格 TMM 带隙，并验证曲线在带隙内的中值符号确为 `+,+,-,-,-,+`。论文测量窗口仍完整绘制，不与严格带隙取交集。
