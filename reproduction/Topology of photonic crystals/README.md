# 《Topological aspects of photonic time crystals》复现

本目录复现 E. Lustig、Y. Sharabi 与 M. Segev 在 *Optica* 5, 1390–1395 (2018) 发表论文的图 1、2、4、5。代码以正式发表版为准；早期 arXiv 版本中的 Fig. 1(c,d) 对应正式版 Fig. 2(a,b)。

## 已修正的主要问题

原实现混用了无量纲时间和论文的 fs 时间，导致图 2 的 120 fs 调制窗口只运行约 19 个而非 60 个周期；同时还使用了错误的背景介电常数、中心动量、脉宽和观测场。当前版本已统一修正：

- `T = 2 fs`，`eps1 = 3`，`eps2 = 1`，自由空间背景 `eps = 1`；
- 图 2 使用论文的 `lambda = 1.4 um / 0.93 um` 和 `220–340 fs` 的 60 周期 PTC；正文写脉宽 `45 fs`，但按当前采用的 base-10 显示约定拟合原图入射包得到约 `35 fs`，默认绘图采用后者并同时保存两者；
- 图 2 现在使用真正的实空间 `D/B` Yee-FDTD：在交错网格上以 leapfrog 有限差分逐步更新旋度，并通过 `E=D/eps(t)`、`H=B/mu` 处理时变本构关系；
- 解析正 `k` 脉冲在初始时只保留含载频的连通 Floquet band/gap，避免极小的高斯谱尾落入相邻动量隙后被 60 周期指数放大；随后不再进行逐界面频谱投影；
- `220–340 fs` 内的 120 个介质跳变全部与整数 FDTD 时间节点严格对齐；更新变量 `D,B` 在时间界面自动连续，跨界面的 `B` 更新使用界面两侧 `E` 的中心平均；
- 带内算例在 `t=400 fs` 明确验收四支出射波，防止代码退化成只在 PTC 首尾各分裂一次的近似；
- 另存前六个时间界面的相干路径树（`2,4,8,16,32,64` 条历史），直观展示每一支在下一界面再次折射/反射；
- 新增独立宽带 Yee-FDTD：保存完整 `D(z,t)` 后依次做空间 FFT、时间 FFT，并把 Floquet 谐波折叠到第一时间布里渊区，生成 `k/k0--Omega*T` 能带强度图；TMM 线只作独立误差审计；
- 图 1 扩展到论文的 `k/k0 = 0..5`，分段绘制能带，避免跨带隙伪连线；
- 图 4 恢复论文的 `3x2` 排版及六个完整测量窗口；曲线由论文内嵌图透明数字化，严格 TMM 带隙只用于独立检验 `+,+,-,-,-,+`，不再截断 (c)、(f)；
- 图 5 传播有限谱宽脉冲，不再把单一域壁本征态的范数误画成脉冲 `|D|`；平滑调制也改为真正连续、周期且时间反演对称的函数。

## 论文参数与数值约定

| 项目 | 数值/约定 |
|---|---|
| 二元介电常数 | `eps1 = 3`, `eps2 = 1` |
| 磁导率 | `mu = 1` |
| 调制周期 | `T = 2 fs` |
| 占空比 | `t1 = t2 = T/2` |
| 时间反演中心 | 两种允许原点均计算；为匹配论文所示 Zak 标签，本实现推断采用低介电常数中心 |
| 匹配论文标签的推断单胞 | `[epsLow(T/4), epsHigh(T/2), epsLow(T/4)]` |
| 动量归一化 | `k0 = 2*pi/(T*c)`；数值坐标中 `c=1` |
| 图 2 色场 | `log10(|D|/max|D(t=0)|)`；论文 caption 只写 `log scale` |
| 本实现图 2 显示窗（由原图坐标估计） | Band: `z=0..135 um, t=0..465 fs`; Gap: `z=0..135 um, t=0..520 fs` |
| 图 2 波包 FDTD | `Nz=8192`, `dz=0.03662 um`, `dt=0.03125 fs`, CFL `≈0.2558`, 每 `0.5 fs` 记录 |
| FFT 能带 FDTD | `Nz=4096`, `dz=0.005855 um`, `dt=0.015625 fs`, 24 周期，`Delta(k/k0)=0.025` |

图 2 的初始振幅采用 `exp[-(x/sigma)^2]`。正式版正文写 FWHM `45 fs`，arXiv v1 写 `5 fs`，但两版使用同一张内嵌图。在当前 base-10 显示约定下拟合多个入射截面得到约 `35--36 fs`；代码因此保留 `p.publishedFwhm=45` 作为文献审计值，但用 `p.inferredRasterFwhm=35` 生成默认复现图。论文没有公开包络函数，也没有说明 45 fs 是场幅还是强度 FWHM；它只写 `log scale` 而未给底数，所以这些均明确属于复现选择而非论文参数。

连通 Floquet 区间的源投影只执行一次；代码随后用 `ifft` 后的实际初态覆盖显示初态，并要求投影相对残差小于 `1e-3`。当前 Band/Gap 残差分别约为 `2.6e-6 / 8.5e-5`，因此不会造成可见的首步跳变或硬截断振铃。

FDTD 求解器采用 `c0=1` 的归一化 Maxwell 方程，因此代码传入 `q=z/c0`，计算后再换回 `z[um]`。这样离散 Courant 数就是 `dt/dq=c0*dt/dz`；若直接把微米网格传入会得到错误的传播速度。波包采用双精度且传播过程中不调用 FFT 滤波。

完整能带不能由 `1.4/0.93 um` 两个窄带波包得到，因此代码另跑宽带局域初场。能带专用网格在 `k/k0=5` 的最短波长处仍有约 20.5 点/波长；FFT 功率逐 `k` 归一化，防止动量隙的指数增长遮住稳定带。灰色隙区及黑色曲线来自 TMM，只作为 FDTD-FFT 结果的审计参照，不冒充 FFT 数据。

图 1/4 的拓扑规范使用时间反演对称单胞；图 2 的有限晶体则在 `t=220 fs` 从一个完整的 `eps1` 半周期开始。这只是同一体能带单胞的循环移位，却会改变有限脉冲耦合系数；该起始相位可恢复论文色标范围内可见的四个带内出射分支，也使 20 周期 TMM 峰值接近正文的 20,000。

论文 Fig. 1(a) 的平台标号与正文“`eps1=3, eps2=1` 且 segment 1 以 `t=0` 为中心”的叙述相互矛盾。闭合 Ω-Wilson 环给出：低介电常数中心对应图中标签 `0,0,pi,0,0,pi,0`；将原点平移 `T/2` 到高介电常数中心后，每条带都增加 `pi`。代码独立计算并保存两套结果，不隐藏这一原文规范歧义。

## 运行

在 MATLAB 中：

```matlab
cd('D:/spacetime_crystal_code/reproduction/Topology of photonic crystals')

fig1_ptc_bands
fig2_fdtd_simulations          % 有兼容缓存时直接读取
fig2_fdtd_simulations(true)    % 强制重算两组波包 FDTD 和宽带 FFT 能带
```

不需要 Signal Processing Toolbox。两组波包缓存包含裁剪后的复数 `D(z,t)`、FDTD/CFL 元数据、四支出射波位置和轨迹验收数据；`fig2_fdtd_fft_band_data.mat` 另存宽带 FDTD 的完整场、折叠后的 FFT 谱和能带脊线。

- 图 2：波包 FDTD 的 CFL 约 `0.2558<1`，120 个时间界面全部严格对齐，传播阶段的频谱滤波必须关闭。前六个界面对应的解析路径树仍展开为 `2,4,8,16,32,64` 条历史，其相干求和与 2x2 传播矩阵的相对误差低于 `1e-11`。

## 必须公开的论文信息缺口

### 1. 图 2 的 60 周期与“约 20,000 倍”不相容

按论文全部文字参数做精确 TMM：

- `lambda = 0.93 um`, 20 周期：相干峰约 `2.16e4`；
- 同一波长，60 周期：相干峰约 `9.64e12`。

因此正文的 60 周期和“约 20,000 倍”不能同时成立。Caption 只说明色条是 `log scale`，没有指定底数；当前代码沿用约 `-1.5..11` 的 base-10 栅格拟合显示范围，但不把这个底数声称为论文已公开参数。超出部分仅在绘图时截色，原始复数场与实际最大增益仍保存在 MAT 数据中。

原图带内两包在 PTC 中的可见斜率约对应 `|v_g|≈0.79c`，而上述文字参数的连续 Maxwell/TMM 结果是 `0.9202c`。只有低至约 3–6 points/λ 的粗 Yee 网格才能用数值色散压到原图斜率；这远低于可靠 FDTD 分辨率，且仍不能同时恢复正文声称的 2.5 倍 Gap 展宽。当前实现使用约 25–38 points/λ 的波包网格，所得结果应收敛到 Maxwell/TMM 轨迹，不通过故意加粗网格拟合论文栅格图。

### 2. 图 5 没有给出脉冲波长和宽度

论文只为图 2 指定 `0.93 um / 45 fs`，并未为图 5 给出相应参数。直接沿用会使 16T 的幅度增至约 712，明显不符原图。当前实现采用由两个 Floquet 单胞本征矢匹配得到的拓扑界面模：

```text
k/k0 = 0.607301466...
lambda = 0.9872937 um
```

有限谱宽（强度 FWHM 约 189 fs）由论文 Fig. 5(b) 的峰包络反演，并明确保存为推断参数，而非声称它由论文给出。
初始脉冲位于 `eps=3` 片段中，因此使用正向波阻抗关系 `B/D=1/sqrt(3)`；有限谱宽中轻微偏离严格域壁模的分量负责论文所示的后期再增长。

### 3. 图 4 的逐点相位参考没有完整公开

论文说明图 4 的相位来自 FDTD 场的傅里叶分量，并由 Eq. (7) 提取，但没有给出探针位置、傅里叶时间门/参考时刻、gap 2--6 的输入谱以及精确的关断相位。这些量会改变逐点相位曲线，因此不能仅凭正文参数唯一重建六条蓝线。

当前实现不再用任意单胞中心的增长 Floquet 模冒充论文逐点 FDTD 曲线，也不再强制加减 `2*pi` 来满足预设符号。六条蓝线由所提供论文的内嵌栅格图数字化；原始蓝线中心像素、端点标定及约 1--2 像素的不确定度全部保存在 `fig4_data.mat`。与此同时，代码采用与 Fig. 1 Zak 标签一致的低介电常数中心单胞，独立细化六个严格 TMM 带隙，并验证曲线在带隙内的中值符号确为 `+,+,-,-,-,+`。论文测量窗口仍完整绘制，不与严格带隙取交集。
