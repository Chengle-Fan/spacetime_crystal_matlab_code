# 通用传输线模块：精简与运行审查

本轮以此前已经修改过的工作区代码为基准，检查公共接口、`private` 依赖、数值结果及默认入口。目标仍是 SSPP/CROW 实验平台的通用模型，物理参数保持可配置。

## 发现并修复的问题

`tl_fdtd_gaussian_k_scan` 的短路端点检查原先使用
`any(probeNodeIndices == [1 nNode])`。这会导致：

- 三个及更多探针时，数组尺寸不一致，合法的内部探针配置无法运行。
- 两个探针时，端点检查依赖排列，例如 `[nNode,64]` 可能漏检短路端点。

现改为集合成员检查 `any(ismember(probeNodeIndices,[1 nNode]))`。
回归覆盖 1、2、3、5 个内部探针，以及包含左右短路端点的不同排列。
这一问题存在于本轮精简前的代码中。

## 进一步精简

- `tl_fdtd_fft_bands` 与 `tl_xt_fft_bands` 共用 `private/tl_fold_power`，通过稀疏整数频率索引映射完成功率累加；保留奇偶网格、频率排序和各探针/通道维度。
- PWE 的整数参数、调制占空比复用已有 `tl_option` 校验，删除重复实现。
- 参数反演复用已构建的基础模型，每次目标函数评估只构建待拟合模型，减少重复计算。

非测试 MATLAB 源文件总行数从 **3872 减至 3834**，净减少 **38 行**；统计包含 `private`、注释和空行。新增回归代码单独计算。没有通过删除稳定性检查、模型快照校验、谱输出或求解路径缩短代码。
