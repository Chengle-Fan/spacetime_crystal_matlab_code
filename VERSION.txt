3.1.0

V3.1 scientific-audit release of the spacetime-media MATLAB package.
Brand name: V3.1.  Semantic package version: 3.1.0.

Scope
-----
- Root Maxwell templates: PWE, temporal TMM, finite-sample D/B-Yee FDTD,
  and finite Gaussian-packet/multi-probe FDTD-FFT.
- Transmission-line templates: one traceable SSPP/CROW circuit model used
  by PWE, temporal TMM, finite-chain Q/Phi FDTD, and FFT diagnostics.
- Paper applications: topology_aspect and Full_momemtum.  Both resolve the
  shared templates explicitly and keep paper data separate from assumptions.

V3.1 physical and numerical hardening
-------------------------------------
- The Maxwell and transmission-line FFT main paths remain real finite-space
  simulations for every source centre k_c.  No Bloch-only or time-only
  propagation replaces the finite sample in order to save computation.
- k_c=0 no longer silently creates a zero magnetic/current state.  Maxwell
  packets use an explicit propagation direction and Yee group speed;
  zero-frequency SSPP packets use the selected k->0 acoustic impedance limit.
- Staggered magnetic/current envelopes are placed at t=-dt/2 and use the
  corresponding discrete Yee/leapfrog carrier frequency and group speed.
- Fixed-probe FFTs use endpoint-free integer-period gates, periodic Hann
  windows, full physical-frequency spectra, explicit modulo-Omega power
  folding, and incoherent multi-probe power addition.  Single-k multi-probe
  matrices are handled without MATLAB singleton-dimension ambiguity.
- FFT amplitudes undo MATLAB ifft scaling and the periodic-Hann coherent
  gain.  Grid-aligned peak power is therefore invariant to zero padding;
  spectral integrals still require the reported frequency/k bin measure.
- Zero padding changes display spacing only.  Raw/folded power, column and
  global normalization, active-column masks, window gains, analysis rows,
  native resolution, and source/solver metadata remain auditable outputs.
- fdtd1d always records the requested terminal state, even when recordEvery
  does not divide nSteps.  Uniform-time tolerances now scale with the actual
  sampling interval and floating-point time magnitude.
- Transmission-line Cpar is now an active additive parasitic capacitance in
  every PWE/TMM/FDTD/fit path; C0 is the nominal modulated contribution.
  PWE Fourier data must match the exact model snapshot.
- The expensive finite-chain stability eigenaudit can be reused across a
  k_c scan only through a validated object containing the exact model and
  boundary topology.  Every k_c still advances the complete finite chain.
- A spatially nonuniform finite-chain capacitance now gives the exact
  requested initial voltage through Q_i=C_i V_i; companion states are
  explicitly labelled as a centre-local narrow-band approximation.  Modal
  group velocity follows energy-overlap tracking (with an explicit heuristic
  warning for lossy non-Hermitian models), and the SSPP zero-k limit must
  pass a directed-power audit.
- maximumPhysicalOmega in the auxiliary signed x-t FFT now actually limits
  the raw bins entering Floquet folding while retaining the full raw spectrum.
- Full_momemtum reports late-time finite-chain envelope rates as finite-window
  diagnostics, not as bulk Im(omega), and its plots retain MATLAB R2020a
  compatibility.

Validation
----------
Run validate_v31_suite() for analytic Maxwell checks, temporal-interface and
FFT edge cases, the complete transmission-line suite, path restoration, and
whole-repository Code Analyzer.  Use

  validate_v31_suite(struct('runPaperSmoke',true))

to add quick finite-sample FDTD-FFT smoke tests for both paper directories.
The suite verifies implementation consistency; it does not replace required
convergence studies in packet FWHM, probe position, sample/boundary distance,
dx, dt, analysis duration, component uncertainty, or experimental calibration.

Environment
-----------
Base MATLAB only.  Declared minimum R2020a; verified on R2026a Update 3.
Legacy pre-V3 code remains recoverable from tag legacy-pre-v3-refactor.
